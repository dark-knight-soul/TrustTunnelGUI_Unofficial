# Changelog

## 1.1.0

### Добавлено
- Локальный SOCKS5-прокси как альтернатива VPN (TUN): порт, доступ из локальной сети, логин и пароль.
  В этом режиме на экране серверов показывается адрес прокси.
- Тёмная тема, режим «как в системе» с отслеживанием настроек Windows, тёмный заголовок окна и меню в трее.
- Английский язык интерфейса.
- Запуск без прав администратора: приложение перезапускается с повышенными правами, только когда это нужно для режима VPN (TUN).
  Добавлен параметр «Всегда запускать от имени администратора».
- Установщик (`TrustTunnelGUI-<версия>-setup.exe`) с удалением через «Установленные приложения»
  и тихими режимами `--silent` / `--uninstall --silent`.
- Portable-версия: настройки и журналы хранятся в папке `data` рядом с программой.

### Изменено
- Автозапуск без прав администратора работает через раздел реестра `Run`, с правами — через Планировщик заданий.
- Новая структура репозитория: `src/`, `installer/`, `scripts/`, `client/`, `docs/`.

## 1.0.0

- Первая версия: интерфейс в стиле TrustTunnel Flutter Client — серверы, профили маршрутизации, настройки, трей.
- Импорт ссылки `tt://` и файла `.toml` через `setup_wizard.exe`.
- Корректная остановка клиента через Ctrl+C; пароли хранятся зашифрованными (DPAPI).
