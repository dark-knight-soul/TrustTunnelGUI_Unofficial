# TrustTunnel GUI для Windows (неофициальный)

Графическая оболочка для консольного клиента [TrustTunnel](https://github.com/TrustTunnel/TrustTunnelClient).
Интерфейс повторяет [TrustTunnel Flutter Client](https://github.com/TrustTunnel/TrustTunnelFlutterClient): серверы, профили маршрутизации, настройки, значок в области уведомлений.

## Возможности

- Серверы: добавление, редактирование, импорт ссылки `tt://` и файла `.toml` (через `setup_wizard.exe`).
- Профили маршрутизации с правилами «Обход» и «VPN», маршрутизация по умолчанию.
- Два режима подключения:
  - **VPN (TUN)** — весь трафик системы идёт через сервер; нужны права администратора;
  - **локальный SOCKS5-прокси** — трафик идёт через сервер только у приложений, настроенных на прокси; работает без прав администратора, по желанию доступен из локальной сети и с логином и паролем.
- Светлая и тёмная тема (или как в Windows), русский и английский язык.
- Журнал клиента, исключённые маршруты, kill switch, автозапуск и автоподключение.
- Корректная остановка клиента (Ctrl+C), чтобы он успел восстановить маршруты и DNS.

## Запуск

Приложение запускается с обычными правами. При подключении в режиме VPN (TUN) оно предложит перезапуститься от имени администратора; в настройках «Запуск и подключение» можно включить «Всегда запускать от имени администратора».

`TrustTunnelGUI.exe` должен лежать рядом с файлами из архива клиента:

```
TrustTunnelGUI.exe
trusttunnel_client.exe
setup_wizard.exe
wintun.dll
```

Настройки хранятся в `%APPDATA%\TrustTunnelGUI` (пароли зашифрованы для текущего пользователя Windows), журналы — в `%APPDATA%\TrustTunnelGUI\logs`.

## Сборка

Нужен только .NET Framework 4.8, который уже есть в Windows 10/11:

```
gui\build.cmd
```

Результат — `TrustTunnelGUI.exe` в корне папки клиента. Отладочная сборка с самотестами и рендерингом экранов в PNG: `gui\build.cmd dev <путь к exe>`.
